# Service.Order

## Description

Service.Order est un microservice développé en Node.js et TypeScript, utilisant MongoDB comme base de données. Ce service gère les fonctions de commande (order) et de livraison (delivery).

## Prérequis

- Node.js (version 20 ou supérieure)
- npm (version 6 ou supérieure)
- MongoDB (version 4 ou supérieure)
